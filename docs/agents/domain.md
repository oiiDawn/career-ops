# Domain Docs

This repository uses a single-context layout:

- `CONTEXT.md` contains the domain glossary and context.
- `docs/adr/` contains architectural decision records.

Before exploring an affected area, read the relevant files when they exist. If they do not exist, proceed silently; domain-modeling skills create them only when needed.

Use terminology defined in `CONTEXT.md`. Surface any proposal that conflicts with an existing ADR instead of silently overriding it.
