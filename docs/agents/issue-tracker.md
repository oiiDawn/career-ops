# Issue Tracker

Issues for this fork are tracked in Linear:

- Workspace and team: `Oii workspace` (`OII`)
- Project: [Career Ops Customization](https://linear.app/oii-workspace/project/career-ops-customization-9c707ba85054)

Use the installed Linear plugin to search, create, and update issues. New issues belong to the `Oii workspace` team and the `Career Ops Customization` project.

Do not use GitHub Issues in the public upstream repository as this fork's issue tracker.
